# agent-skills

A library of skills for AI agents. Each skill provides a procedure with connected actions, decision criteria, and verifiable results.

## Skills

Choose a skill for the task you want to complete. Follow its link to read the full procedure.

| Skill | Purpose |
| --- | --- |
| [procedural-skill-creator](skills/procedural-skill-creator/SKILL.md) | Create or revise skills by defining their scope, designing their workflow, writing instructions, removing repetition, and checking the complete procedure. |

## Install

Open a terminal in the project where you want to use the skills, then run:

```sh
npx skills add LeszekKantorek/agent-skills
```

Follow the prompts to choose the skills and the AI agent you use. You can install only the skills you need.
