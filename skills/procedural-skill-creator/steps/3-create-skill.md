# Create or update the skill

## Goal

Create a skill that expresses the established capability and designed procedure.

## Procedure

Use [working-example.md](../references/working-example.md) and its relevant linked steps as a reference for expressing instructions and organizing delegated procedures, not as a prescribed structure or set of tasks.

Create or update `SKILL.md` in English with the name, selection description, and procedure derived from the capability. State the intended outcome of the complete procedure.

For orchestrated skills, use `SKILL.md` to guide the lead agent. Describe the delegated steps, their responsibilities, and expected results. Place their execution instructions in `steps/<number>-<step>.md` files focused on the goal and procedure.

Place supporting resources where the agent can access them. Identify when each resource is needed and avoid requiring unrelated reading.

Save the skill and its required resources in the requested location. Provide the created or updated skill to the lead agent for verification.
